# Podstawy Technologii Webowych - Laboratoria

Zbiór projektów i zadań laboratoryjnych zrealizowanych w ramach zajęć na Wyższej Szkole Informatyki i Zarządzania (WSIiZ) w Rzeszowie. 

Repozytorium zawiera 9 praktycznych laboratoriów, które obrazują stopniowy rozwój umiejętności w zakresie tworzenia stron internetowych, od podstawowej struktury dokumentu po interaktywne skrypty po stronie klienta.

## Wykorzystane technologie
* **HTML5:** Semantyczna struktura stron, formularze, multimedia.
* **CSS3:** Stylowanie elementów, Flexbox/Grid, responsywność (RWD).
* **JavaScript (Vanilla JS):** Manipulacja modelem DOM, obsługa zdarzeń (events), podstawowa logika aplikacji.

## Przegląd laboratoriów
Projekty są podzielone na foldery odpowiadające kolejnym etapom nauki:
* **Laboratorium 1-2:** Wprowadzenie do HTML i CSS. Podstawowe formatowanie tekstu i struktura dokumentu.
* **Laboratorium 3-4:** Rozbudowane arkusze stylów (CSS), pozycjonowanie elementów i pierwsze skrypty JavaScript.
* **Laboratorium 5-7:** Zaawansowana manipulacja DOM, walidacja formularzy i interakcja z użytkownikiem za pomocą JavaScript.
* **Laboratorium 8-9:** Złożone zadania algorytmiczne w JS i finalna integracja poznanych technologii webowych.
